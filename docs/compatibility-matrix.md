# ACT compatibility matrix

Baseline: ACT **3.8.5.288**. Inventory date: **2026-10-21**.
This matrix tracks the work needed to grow the embedded host into an ACT
replacement. It is a feature and API-family inventory, not an exhaustive list of
every public member or a claim of compatibility with every ACT plugin.

Implementation and verification are separate: a passing probe establishes only
the behavior it exercises. Evidence below comes from source, test definitions and
recorded validation reports. The initial inventory did not rerun tests; later execution and changes are recorded in [additional plugin validation](additional-plugin-validation.md).

## Reading the status

| Axis           | Value       | Meaning                                                                        |
| -------------- | ----------- | ------------------------------------------------------------------------------ |
| Implementation | Implemented | The stated bounded feature has an implementation                               |
| Implementation | Partial     | A subset exists; the row identifies missing behavior                           |
| Implementation | Missing     | No implementation was found for the stated feature                             |
| Verification   | Reference   | Selected contracts execute against genuine ACT and the replacement             |
| Verification   | Plugin      | Original plugin execution is recorded; this alone is not ACT equivalence |
| Verification   | Contract    | Replacement/fixture checks exist; no original comparison is claimed            |
| Verification   | Unverified  | No validating execution evidence was identified for the stated scope           |

The official [feature list](https://advancedcombattracker.com/) and
[API documentation](https://advancedcombattracker.com/apidoc/html/T_Advanced_Combat_Tracker_FormActMain.htm)
provide discovery references. The pinned executable and independent probes remain
the authority for version-specific behavior; online documentation may describe a
different version.
