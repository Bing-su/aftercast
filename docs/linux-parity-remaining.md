## Recommended next bounded unit

L7a is now implemented through the existing ACT XML/gzip interchange and
include-log-lines flag, with temporary-file worker/controller regressions; private
history is unchanged. L6a now has managed policy, Bridge/Rust admission and
GUI/controller wiring implemented.
The remaining raw-import slices are L6b–L6d.
Then deliver L8a with the first actual report (L8b), rather than a broad unused
report framework. This is a recommendation to review before edits, not an extra
feature implementation in this checkpoint.

Linux-capable parity is therefore **not complete**. The remaining work is finite
and primarily technical; there is no need to ask a product-policy question merely
to implement a verified ACT behavior. Actual native execution, external services,
plan-only WinForms work and stronger recording durability keep the separate
boundaries above.

Graph report options now persist in the application configuration as described in [hierarchical-reports.md](hierarchical-reports.md). The remaining L7b/L9d gaps include ACT custom GDI graph delegates, native rendering and unrelated output settings; L9e still includes ACT-specific fonts and color rules. L7c ODBC requires distinguishing local configuration/SQL generation from an actual external database connection. L8 analysis items remain scoped individually above; no external service has been contacted.

ACT defaults and remaining main-table differences are documented in [main-table-options.md](main-table-options.md).
