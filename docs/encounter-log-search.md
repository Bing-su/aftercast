# Encounter log search and copy contract

The decompiled ACT `FormEncounterLogs` keeps an ordered copy of encounter log entries. Text search uppercases the search text and each line using the current .NET culture, then marks matching entries; an empty query matches every entry. Regex search uses .NET `RegexOptions.IgnoreCase`. Search resets the cursor. Next and previous scan without wrapping. The result-only view preserves the search-result order and selection refers to the visible view. Copy Results uses all marked source entries; Copy All uses every source entry; Copy Selection uses selected visible entries; Copy Combat includes entries whose type is neither 0 nor -1. Copy operations append `Environment.NewLine` per row. These observations are from decompiled ACT code, not native-form execution.

The `aftercast::log_search` library now provides bounded in-memory text matching, adjacent-match navigation and copy-text construction over caller-owned ordered rows and stable indices. The caller maps result-only selections back to source indices. The caller supplies the newline, and output is limited to 16 MiB. Rust Unicode uppercasing is culture-independent and can differ from ACT current-culture casing. No clipboard is accessed. Regex search, type-filter UI, highlight/result-only display, snapshot acquisition and GUI/controller integration remain unimplemented. No whole-encounter consistency is implied by combining independently fetched live pages.
