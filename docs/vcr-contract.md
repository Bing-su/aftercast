# Encounter VCR implementation and limits

ACT's `FormEncounterVcr` and `VcrCombatant` read the existing encounter graph; moving the cursor does not reparse input or publish parser/trigger callbacks. The 250 ms timer advances Play once every four ticks and rewind/fast-forward once per tick. The interaction lookback includes both endpoints; inactive non-allies are retained if targeted in the preceding 15 seconds. The graph shows category totals and inferred health, not game-world coordinates. These observations come from decompiled ACT code, not a native form execution.

Aftercast captures an owned graph and matching retained logs under one combat lock. Captures invalidate the previous VCR revision; a completed Rust copy remains independent. The explicit live-follow control obtains a new snapshot of the active encounter. Pausing, ending, cancelling, closing, selection/session changes and failed requests prevent late results from being applied. Cancel and close discard the UI result; a read-only capture already admitted to the worker may still finish. Replaying an existing copy does not invoke the parser or triggers. Copied log omissions and partial-import status are displayed.

The capture is limited to 512 actors, 1,024 categories, 4,096 entries per registration set, 65,536 copied action rows, 65,536 retained log rows, 64 MiB encoded data and 100 hours; a frame has a four-million-operation budget. These are aftercast safeguards, not ACT limits. The screen displays at most 128 actors and 512 interactions and reports the full counts. Layout is generated and does not reproduce native styling. The UI uses consistently sorted incoming actions for inferred health: ACT's initial draw can observe original incoming order before its `Instances` property sorts that list in place. Avoiding mutation of the stored encounter avoids that first-frame side effect.

The interaction diagram uses the same selected-category lookback totals, but its undirected lines omit ACT arrow opacity and category colors. ACT uses a one-second default lookback and forces at least one second while linked. Timeline full-log highlighting remains separate parity work. Native Windows VCR rendering, physical controls and timing have not been exercised. Independent review remains pending due to the existing review quota limit.
